# lcls-timing-core

lcls-timing-core is the SLAC LCLS-I and LCLS-II timing firmware library: the timing receiver core, the LCLS-II event receiver (EVR), the legacy LCLS-I EVR, and the transceiver (GT) wrappers, together with the `LclsTimingCore` PyRogue drivers and YAML register maps. It is used by firmware engineers who integrate the timing receiver, EVR, and GT wrappers into a design through ruckus, and by software users of the `LclsTimingCore` PyRogue package.

Documentation: https://slaclab.github.io/lcls-timing-core/
